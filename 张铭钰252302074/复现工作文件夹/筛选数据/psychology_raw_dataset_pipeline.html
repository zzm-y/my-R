目标

从多个CSV文件中找到psychology领域的文章及其原始数据集

  • 输入：4个CSV文件
  • 处理：数据筛选、合并、回查
  • 输出：有raw dataset可用的psychology文章列表

数据文件概览

文件名 主要内容 关键字段
score_rr-project_status.csv RR项目状态 paper_id, rr_id, field
pr_outcomes.csv PR结果 paper_id, data_available
orig-material_availability.csv 原始材料可用性 pdf_filename, pr_data_available...11
orig-material_author-outreach.csv 作者联系记录 pdf_filename, paper_id

Pipeline流程图

score_rr-project_status.csv
        │
        │ filter(field == "psychology")
        ▼
psychology paper_id / rr_id list
        │
        │ left_join by paper_id
        ▼
pr_outcomes.csv
        │
        ├─ data_available
        ├─ data_location_description
        ├─ data_notes
        └─ code_available
            │
            ├─ 信息够：直接拿链接
            └─ 信息不够：回查原始文件

步骤1：筛选Psychology文章

# 读取数据
rr_status <- read.csv("score_rr-project_status.csv", stringsAsFactors = FALSE)

# 筛选psychology领域
psychology_papers <- rr_status %>% 
  filter(field == "psychology")

# 查看各领域的文章数量
field_counts <- rr_status %>%
  group_by(field) %>%
  summarise(count = n()) %>%
  arrange(desc(count))

kable(field_counts, col.names = c("领域", "文章数"))

共140篇psychology文章

步骤2：Join pr_outcomes.csv

# 读取PR结果数据
pr_outcomes <- read.csv("pr_outcomes.csv", stringsAsFactors = FALSE)

# Left join by paper_id
merged_data <- psychology_papers %>%
  left_join(pr_outcomes, by = "paper_id")

# 查看关键字段
key_fields <- merged_data %>%
  select(paper_id, rr_id, data_available, 
         data_location_description, data_notes) %>%
  head(5)

kable(key_fields, col.names = c("Paper ID", "RR ID", "数据可用", 
                                 "数据位置描述", "备注"))

步骤3：检查数据可用性

# 查看有数据可用的文章
has_data <- merged_data %>% 
  filter(data_available == "Yes")

cat("有raw dataset可用的记录数：", nrow(has_data), "\n")
cat("对应的唯一paper_id数：", length(unique(has_data$paper_id)), "\n")

# 数据位置分布
location_summary <- merged_data %>%
  filter(data_available == "Yes") %>%
  mutate(location_type = case_when(
    grepl("OSF", data_location_description) ~ "OSF平台",
    grepl("journal|Science Direct|Wiley|Sage", data_location_description) ~ "期刊网站",
    grepl("author|website", data_location_description) ~ "作者网站",
    grepl("GitHub", data_location_description) ~ "GitHub",
    TRUE ~ "其他"
  )) %>%
  group_by(location_type) %>%
  summarise(count = n()) %>%
  arrange(desc(count))

kable(location_summary, col.names = c("数据位置", "数量"))

完整Pipeline代码

# 完整的数据处理流程
result <- rr_status %>%
  filter(field == "psychology") %>%
  left_join(pr_outcomes, by = "paper_id") %>%
  filter(data_available == "Yes") %>%
  left_join(orig_availability, by = "pdf_filename") %>%
  left_join(orig_outreach, by = "pdf_filename")

# 保存结果
write.csv(result, "psychology_raw_dataset_final.csv", row.names = FALSE)

# 查看摘要
summary_result <- result %>%
  group_by(data_available) %>%
  summarise(count = n())

print(summary_result)

关键发现

  1. 140篇 psychology文章中筛选出52条有可用数据的PR记录
  2. 主要托管平台：OSF (60%)，其次是期刊官网 (30%)
  3. 数据格式多样：CSV, SAV (SPSS), Excel, R数据文件
  4. 部分数据需要机构访问权限
  5. 有些只包含部分实验数据

建议：优先使用OSF平台的数据，因其提供永久存储和版本控制
